# Broker Portal API Guide (v2)

This guide describes version 2 of the Broker Portal API, which replaced version 1 in May 2024. The base URL is `https://api.ragbench-mutual.example/v2`.

## Authentication

Every request carries a scoped service token in the `Authorization` header and the customer's tenant in `X-Tenant-Id`. A request without the tenant header fails with error code BP-5001.

```bash
curl -X POST https://api.ragbench-mutual.example/v2/submissions \
  -H "Authorization: Bearer $TOKEN" \
  -H "X-Tenant-Id: northstar-mutual" \
  -F "packet=@harbor-packet.pdf"
```

## Limits

- Rate limit: 120 requests per minute per API key. Exceeding it returns HTTP 429 with error code BP-5044 and a `Retry-After` header.
- Maximum packet size: 50 MB per submission.
- Accepted file types: PDF, DOCX, TXT, and email-body submissions.
- Idempotency keys are honored for 24 hours.

## Create a submission

`POST /v2/submissions` accepts a multipart upload and returns immediately with a submission id. Processing is asynchronous.

```json
{
  "submission_id": "sub_01HZX8Q3",
  "status": "queued",
  "product": "harborshield",
  "request_id": "req_7f31c2"
}
```

## Poll for status

`GET /v2/submissions/{submission_id}` returns one of `queued`, `extracting`, `reviewed`, or `failed`. A `failed` status carries an `error_code` field that maps to the Error Code Reference.

```json
{
  "submission_id": "sub_01HZX8Q3",
  "status": "failed",
  "error_code": "HS-4130",
  "request_id": "req_7f31c2"
}
```

## Webhooks

Register a webhook with `POST /v2/webhooks`. Deliveries are signed with an HMAC-SHA256 signature in the `X-Signature` header and retried up to 5 times with exponential backoff.

# Incident Report INC-2024-0630: Malformed Routing Rule Crashed the ClaimPilot Router

**Severity:** 1. **Date:** 2024-06-30. **Owner:** Elias Ren.

## Timeline

The incident began at 02:40 UTC and ended at 03:05 UTC, a duration of 25 minutes. It happened on a Sunday, so traffic was low.

## Impact

7 customers saw ClaimPilot fail to route new loss notices. Notices received during the incident were queued and routed after recovery. No customer data was lost.

## Cause

A malformed routing rule was pushed to a tenant configuration without running `claimpilot validate-routing`. The second-generation router crashed when it loaded the rule.

## Corrective actions

- Make routing validation a mandatory step in the configuration pipeline. Owner: Tomasz Wrona.
- Add a safe-load fallback so that an invalid rule is skipped rather than crashing the router. Owner: Elias Ren.

# HarborShield AI Release History

Release history for HarborShield AI, newest first. Limits listed in an entry apply until the next entry that changes them.

## 2.1 (2024-08-19)

- CSV export now includes the sanctions rationale column, closing the limitation that shipped with Solstice 2.1.
- Sanctions list snapshots refresh every 6 hours on the standard plan.

## 2.0 (2024-05-06)

- Rebuilt the API as version 2 of the Broker Portal API.
- Raised the rate limit from 60 to 120 requests per minute per API key.
- Raised the maximum packet size from 25 MB to 50 MB.

## 1.4 (2024-02-20)

- Shipped with Solstice 2.1. Added PDF risk memo export for the Broker Portal. CSV export omits the sanctions rationale.

## 1.2 (2024-01-09)

- Raised the rate limit from 30 to 60 requests per minute per API key.
- Raised the maximum packet size from 10 MB to 25 MB.

## 1.0 (2023-09-18)

- General availability. Rate limit of 30 requests per minute per API key and a maximum packet size of 10 MB.

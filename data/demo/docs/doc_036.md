# ClaimPilot Changelog

Release history for ClaimPilot, newest first. Each entry lists behavior changes that affect routing, limits, or labels.

## 2.4 (2024-09-03)

- Lowered the auto-escalation confidence threshold from 0.80 to 0.75 after Northstar Mutual reported too many under-escalated notices.
- Added the Spanish-language adjuster note template, enabled by the `FF_SPANISH_NOTES` flag.

## 2.3 (2024-06-11)

- Raised the maximum notice length from 20,000 to 40,000 characters.
- Improved queue-routing adapter retry behavior.

## 2.2 (2024-04-23)

- Introduced the queue-routing adapter for Guidewire ClaimCenter.
- Turned on the second-generation router (`FF_ROUTE_V2`) by default.

## 2.1 (2024-02-20)

- Shipped with the Solstice 2.1 release. Upgraded the severity classification model.
- Raised the auto-escalation confidence threshold from 0.70 to 0.80.

## 2.0 (2023-11-06)

- Added the critical severity label, so ClaimPilot now uses four labels: low, medium, high, and critical.
- Raised the maximum notice length from 8,000 to 20,000 characters.

## 1.4 (2023-07-10)

- Raised the auto-escalation confidence threshold from 0.60 to 0.70.

## 1.0 (2023-02-14)

- First general release. Three severity labels (low, medium, high), an auto-escalation confidence threshold of 0.60, and a maximum notice length of 8,000 characters.

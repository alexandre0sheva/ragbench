# Aurora Risk Suite: Enterprise Plan Sheet

Aurora Risk Suite Enterprise is the top-tier plan for portfolio analytics. This sheet lists what the plan includes.

## Pricing and seats

- Price: $149 per seat per month, billed annually.
- Minimum seats: 50.
- Maximum seats: no maximum.

## Workspace limits

- Scenario Board scenarios per workspace: 100.
- Export row cap: 500,000 rows per XLSX export.
- Data retention: 84 months.

## Support

- Support response time: 1 hour, around the clock.
- Single sign-on: included.

Plans can be changed at renewal. Usage above a plan's limits is blocked rather than billed; an export that exceeds the row cap fails with error code AR-3308.

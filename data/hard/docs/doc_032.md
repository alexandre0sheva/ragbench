# Port Avalen harbour tariff, 2021 edition

Issued by the Port Avalen Harbour Board. This edition takes effect on 1 January 2021 and is the first consolidated edition.

| Charge | Rate |
| --- | --- |
| Berth fee, per metre of length per day | MC 2.64 |
| Pilotage, per movement | MC 398 |
| Container handling, per TEU | MC 51 |
| Waste reception, per call | MC 120 |

Charges are invoiced to the ship's agent after departure. Vessels on scheduled ferry services pay under a separate agreement. Disputes about an invoice must be raised within thirty days.

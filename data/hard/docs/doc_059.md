# Orca 900 specification sheet, revision A

Revision A, effective 16 June 2023. The Orca 900 is a workboat designed and built by Tessaline Marine.

| Item | Value |
| --- | --- |

| Warranty | 24 months |
| Endurance | 12.8 hours |
| Top speed | 42 knots |

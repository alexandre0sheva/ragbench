# Petrel P2 specification sheet

The Petrel P2 is a survey drone designed and built by Vantor Aerial.

| Item | Value |
| --- | --- |
| List price | MC 9,590 |
| Warranty | 24 months |
| Endurance | 7.7 hours |
| Maximum payload | 9 kg |
| Weight | 52.1 kg |

The battery pack is supplied by Norrland Batteries. The lens assembly is supplied by Orlan Glassworks.

# Fathom F5 specification sheet

The Fathom F5 is a sensor buoy designed and built by Brightwater Instruments.

| Item | Value |
| --- | --- |

| Warranty | 24 months |
| Endurance | 3.6 hours |
| Depth rating | 2,744 m |
